# Anglo arrange — reference

Sources distilled for C/G 30-button **harmonic / song** style (not Irish ornament-first).

## Authorities

- Roger Digby, *Anglo File* / *Faking It* — https://www.concertina.com/digby/
  - RH tune + LH chords; bellows direction is led by the melody.
  - Keep chord changes crisp; don’t let every bellows reverse force a muddy chord smear.
- ICA workshop handout *C (push) G7 (pull)* — two-chord vamp on one LH shape.
- VFMC *Introducing The Anglo Concertina* — home-row triad diagrams for C and G.
- Concertutor / Noel Hill cross-row notes — duplicates exist to avoid chops; G-row A draw is a “friend” button (mirror on RH: prefer alternates that keep phrasing smooth).
- Gary Coover harmonic-style tutors — RH melody + LH accompaniment repertoire model.
- Michael Eskin Anglo fingering tools — https://michaeleskin.com/tools/anglo-fingerings.html (Wheatstone cross-row solutions).

## Wren 2 (user instrument)

- Layout: **Wheatstone** C/G.
- RH top-right pull = **F6** (`f'''`).
- RH bottom-right pull = **♯F6** (`f#'''`).
- RH `e''` = mid-row push only; same-octave pull `e''` is **left** bottom-row outer pull.

## Anti-patterns (from this project)

- Changing melody octave (e.g. Mars to `c'''`) only to stay on pull.
- Putting a major cadence under Dm/Am all the way through.
- Push G then immediately pull the same G (empty reversal).
- Assuming RH has pull `e''` — it does not; use LH or accept a flip / higher `e'''`.
